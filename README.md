## Описание проекта

В данной практической работе реализован эмулятор командной строки UNIX-подобной операционной системы.

Для разработки использован язык Python и библиотека Tkinter, с помощью которой сделан графический интерфейс программы.

Эмулятор поддерживает несколько команд для работы с файлами и папками, а также позволяет запускать заранее подготовленные скрипты.

Для работы с файлами используется виртуальная файловая система (VFS). При запуске программа загружает файлы и папки из указанной директории компьютера в оперативную память. Все дальнейшие изменения происходят внутри эмулятора, поэтому настоящие файлы на компьютере не изменяются.

Работа разделена на пять этапов, каждый из которых сохранён отдельным коммитом.

## Требования

Для запуска программы необходимо:

- Python версии 3.10 или новее.
- Библиотека Tkinter (обычно входит в состав Python).
- Windows, Linux или macOS.

Дополнительные библиотеки устанавливать не требуется.

## Запуск программы

На Windows нужно открыть командную строку в папке проекта и выполнить:

```cmd
run.bat --vfs examples/vfs/deep
```

После запуска откроется окно эмулятора, в котором можно вводить команды.

На Linux или macOS запуск выполняется командой:

```bash
./run.sh --vfs examples/vfs/deep
```

Также программу можно запустить напрямую через Python:

```bash
python -m src.main --vfs examples/vfs/deep
```

Если путь к VFS не указан, используется папка `examples/vfs/minimal`.

Заголовок окна формируется из имени пользователя и имени компьютера, на котором запущена программа.

### Параметры запуска

| Параметр | Назначение |
|---|---|
| `--vfs` | Путь к папке виртуальной файловой системы |
| `--script` | Путь к файлу со стартовыми командами |
| `--headless` | Запуск без графического интерфейса для проверки |
| `--help` | Вывод справки по параметрам |

Пример запуска со стартовым скриптом:

```cmd
run.bat --vfs examples/vfs/deep --script examples/startup/all_commands.txt
```

При запуске программа выводит выбранные параметры.

## Команды эмулятора

В программе реализованы следующие команды:

| Команда | Описание |
|---|---|
| `ls` | Показывает содержимое текущей папки |
| `cd` | Позволяет переходить между папками |
| `cal` | Выводит календарь |
| `whoami` | Показывает имя пользователя компьютера |
| `mkdir` | Создаёт папку в виртуальной файловой системе |
| `conf-dump` | Выводит настройки эмулятора |
| `exit` | Завершает работу программы |

Команды `ls` и `cd` также поддерживают указание пути.

Для команды `cal` можно указать год или месяц и год:

```bash
cal
cal 2026
cal 10 2026
```

Команда `mkdir` создаёт только один каталог по указанному пути. Родительская папка должна уже существовать.

Парсер разделяет введённую строку по пробелам. Поддержка кавычек и путей с пробелами в этом варианте не реализована.

## Пример работы программы

После запуска эмулятора можно проверить следующие команды:

```text
/ $ ls
projects

/ $ cd projects/python

/projects/python $ ls
src
tests

/projects/python $ mkdir test

/projects/python $ ls
src
test
tests

/projects/python $ whoami
Petrosyan
```

В этом примере команда `mkdir test` создаёт новую папку `test` внутри виртуальной файловой системы.

Если закрыть программу и открыть её заново, папки `test` уже не будет, так как изменения не сохраняются на диск.

### Обработка ошибок

В программе предусмотрена обработка неправильных команд и аргументов.

Например, при вводе неизвестной команды:

```text
/ $ abcd
Ошибка: неизвестная команда: abcd
```

Если попытаться перейти в несуществующую папку:

```text
/ $ cd unknown
Ошибка: cd: Путь не найден: /unknown
```

При ошибке в интерактивном режиме программа продолжает работать, и пользователь может вводить следующие команды.

## Этапы выполнения работы

### Этап 1. REPL

На первом этапе создано графическое окно эмулятора с помощью Tkinter.

Реализован ввод команд и простой парсер, который разделяет название команды и аргументы.

Добавлены команды `ls` и `cd`, которые на этом этапе работают как заглушки, а также команда `exit`.

Предусмотрено сообщение об ошибке при вводе неизвестной команды или неправильных аргументов.

### Этап 2. Конфигурация

На втором этапе добавлена возможность задавать параметры программы при запуске.

Поддерживаются путь к виртуальной файловой системе и путь к стартовому скрипту.

Стартовый скрипт содержит команды, которые выполняются автоматически. При этом показываются введённые команды и результаты их выполнения.

Если во время выполнения скрипта возникает ошибка, его работа останавливается.

Также добавлена команда `conf-dump`, которая выводит настройки программы в формате «ключ=значение».

### Этап 3. Виртуальная файловая система

На третьем этапе добавлена виртуальная файловая система (VFS).

При запуске эмулятор считывает содержимое выбранной папки компьютера и сохраняет его в оперативной памяти.

Для проверки подготовлены три примера:

- `minimal` — минимальная файловая система.
- `files` — файловая система с несколькими файлами и папками.
- `deep` — файловая система с несколькими уровнями вложенности.

Все операции выполняются с данными в памяти. Исходные файлы и папки на компьютере остаются без изменений.

### Этап 4. Основные команды

На четвёртом этапе реализована полноценная работа команд `ls` и `cd` с виртуальной файловой системой.

Также добавлены две новые команды:

- `cal` — вывод календаря.
- `whoami` — вывод имени текущего пользователя операционной системы.

Добавлена обработка ошибок, например попытки перехода в несуществующую папку.

### Этап 5. Дополнительная команда

На пятом этапе реализована команда `mkdir`.

Она позволяет создавать новые каталоги внутри виртуальной файловой системы.

Перед созданием папки программа проверяет указанный путь и существование родительского каталога.

Созданные каталоги хранятся в оперативной памяти. После закрытия программы все изменения пропадают.

Для проверки работы команды подготовлены отдельные тесты и примеры.
